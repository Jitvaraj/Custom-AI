# Jarvis AI Assistant

A high-performance, futuristic AI assistant built as a pure client-side web application.

## Features

- **Multi-Model Support**: Seamlessly switch between Google Gemini, OpenAI, Anthropic, DeepSeek, Groq, and custom REST API providers.
- **Local Persistence**: All conversation history, user profiles, and API keys are securely stored in your browser's LocalStorage.
- **Control Center**: Advanced sidebar for managing history, API keys, system instructions, and plugins.
- **Plugins & Integrations**: Support for external tools including Internet Search (Grounding) and GitHub integration.
- **Self-Coder Mode**: Toggleable mode for generating code patches and refactoring rules.
- **Progressive Web App (PWA)**: Installable directly to your device for a native-like experience.

## Getting Started

1. **Prerequisites**: Ensure you have Node.js and npm installed.
2. **Install**: Run `npm install` to set up dependencies.
3. **Configure**: Copy `.env.example` to `.env` and set your preferred API keys.
4. **Run**: Use `npm run dev` to start the development server.
5. **Build**: Run `npm run build` to generate a static production build.
