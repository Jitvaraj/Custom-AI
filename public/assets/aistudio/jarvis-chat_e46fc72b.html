Here's a minimal version. It delays the call until the user stops triggering it for wait ms.

javascript 
const debounce = (fn, wait) => {
  let t;
  return (...args) => {
    clearTimeout(t);
    t = setTimeout(
      () => fn(...args), wait
    );
  };
};

Use it on inputs or resize events to avoid firing on every keystroke.

Sure — pass { leading: true } and it'll fire immediately on the first call, then ignore repeats until the wait ends.
